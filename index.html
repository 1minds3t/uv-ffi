uv-ffi
uv is a world-class CLI tool. uv-ffi re-architects its resolver and installer as a resident engine — keeping the Tokio runtime, HTTP connection pools, site-packages metadata, and interpreter state warm across calls. Speed limited only by filesystem I/O.

how it works
⚡
Persistent Engine
A OnceLock UvEngine singleton holds the Tokio runtime, TLS pools, interpreter metadata, and site-packages index. Initialized once at import (~65ms). Every subsequent call skips cold startup entirely.
🚀
Zero-Clap Fast Path
pip install commands hit a hand-written token parser — no clap parsing, no arg validation overhead. Internal Rust structs are constructed directly. Saves ~2ms per call. Falls back to full clap on unrecognized flags automatically.
🫧
Bubble Installs
--target installs route through a pre-warmed BUBBLE_ENVIRONMENT — resolver sees a clean slate, main env cache is never touched. How omnipkg generates multi-version isolated environments entirely in-memory.
🔄
Zero-Disk Cache Update
After every install, SITE_PACKAGES_CACHE is updated directly from the resolver's in-memory changelog — no dist-info scan, no filesystem I/O. Post-install cache update cost: 0.0ms.
🩹
Auto-Heal
If an external tool (vanilla uv, pip) modifies the environment behind uv-ffi's back, the engine detects the stale dist-info on next call, drops the RAM cache, rescans, and retries transparently. Caller always gets a correct result.
🔧
C ABI
omnipkg_uv_run_c(cmd, out_json, max_out) — callable from Go, C++, Rust, or any language with C FFI. Returns exit code and writes a JSON install/remove changelog to the output buffer.
usage
python — warm daemon worker
# import and keep alive in a long-lived process
from uv_ffi import run, patch_site_packages_cache, get_site_packages_cache
 
# first call initializes engine — ~65-75ms one-time cost
rc, installed, removed, warnings = run('pip install --python /usr/bin/python3 rich==14.3.2')
 
# subsequent calls use warm engine — ~5-6ms
rc, installed, removed, warnings = run('pip install --python /usr/bin/python3 rich==14.3.3')
# installed=[('rich', '14.3.3')] removed=[('rich', '14.3.2')]
 
# surgical cache patch — ~25µs, no disk I/O
patch_site_packages_cache(installed=[['rich', '14.3.3']], removed=[['rich', '14.3.2']])
 
# inspect in-memory env state — zero disk I/O
state = get_site_packages_cache()
# [('rich', '14.3.3'), ('requests', '2.31.0'), ...]
 
❯
⚠ The gains only materialize when the engine stays warm across calls in the same process. Calling uv-ffi via a new subprocess each time (~73ms) is slower than calling uv directly (~19ms).
